## Getting Started

### Prerequisites

Make sure you have Python 3 installed on your system.

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/satvikprofessional2006-stack/Web-Dev-assingment-1-sem3.git
   cd Web-Dev-assingment-1-sem3
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

   **Windows:**

   ```bash
   venv\\Scripts\\activate
   ```

   **macOS/Linux:**

   ```bash
   source venv/bin/activate
   ```

3. Install dependencies if a `requirements.txt` file is included:

   ```bash
   pip install -r requirements.txt
   ```

## Running the Project

Run the project using the entry-point Python file included in the repository. For example:

```bash
python app.py
```

If the project uses a different entry point, replace `app.py` with the appropriate filename.
